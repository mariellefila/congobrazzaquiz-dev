# **9. Breakpoints**

Je garderais une grille simple et prévisible.

| **Breakpoint** | **Valeur** | **Usage** |
| --- | --- | --- |
| `xs` | `< 480px` | Petit smartphone |
| `sm` | `480–639px` | Smartphone |
| `md` | `640–767px` | Grand smartphone |
| `lg` | `768–1023px` | Tablette |
| `xl` | `1024–1279px` | Desktop |
| `2xl` | `≥ 1280px` | Grand desktop / Salle |

### **Règles principales**

**< 640px**

- une colonne ;
- boutons principaux `width:100%` ;
- formulaires empilés ;
- modales presque plein écran.

**≥ 1024px**

- layouts desktop complets ;
- formulaire + aperçu côte à côte ;
- lobby / règles en colonnes ;
- sidebar admin visible.

**≥ 768px**

- grilles 2 colonnes possibles ;
- cards catégories en 2 ou 4 colonnes selon largeur.

**≥ 1280px**

- grands écrans ;
- utilisation optimisée du Mode Salle ;
- contenu limité par `max-width` pour éviter les lignes trop longues.
